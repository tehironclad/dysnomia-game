# Folklore cartridges

These `.fkc` cartridges are **Maria's own original work**: the seed cartridges of the Folklore
Cartridge Gallery, generated by her `cartridges/build.js` ("production guided by code processes,
not manual editing", Maria, day-909 brief). They are copied unchanged, with `manifest.json`, from
`tehironclad/entropy-ai-pulse` `cartridges/`. Their titles and themes are hers; keep them.

| File | Title | Type |
|---|---|---|
| `corner.fkc` | Corner Pixel | sprite |
| `frame.fkc` | Frame | sprite |
| `entropy-e.fkc` | Entropy E | sprite |
| `bolt.fkc` | Bolt | sprite |
| `heart.fkc` | Heart | sprite |
| `target.fkc` | Target | sprite |
| `sweep.fkc` | Sweep | game |
| `bounce.fkc` | Bounce | game |
| `odometer.fkc` | Odometer | game |
| `static.fkc` | Static | game |

The format is entropy-ai-pulse `docs/FOLKLORE_CARTRIDGE_SPEC.md` (the manifest's `spec` path is
relative to that repository): a 16-byte `FKC` header, then 6502 code loaded at `$0200`, drawing a
64×64 one-bit framebuffer at `$E000`–`$E1FF` (MSB = leftmost pixel). A bare `RTS` or `BRK` ends a
cartridge; an unofficial opcode stops it as `bad`.

They run in the game on `scripts/arcade/fk6502.gd` (a port of the site's `lib/folklore-cpu.js`) via
`scripts/arcade/folklore_cart.gd`. `tests/test_arcade.gd` checks every cartridge's framebuffer against
the site's JS and the manifest's `litPx`.

## The cabinet's I/O page (our convention, not Maria's spec)

The spec defines no input or score registers, and none of these cartridges reads any. So that new
game cartridges can be played on the in-world cabinets, the player writes a small I/O page right after
the framebuffer:

| Address | Meaning |
|---|---|
| `$E200` | input, written before every frame: bit0 left, bit1 right, bit2 up, bit3 down, bit4 fire |
| `$E201` | frame counter, +1 per 60 Hz frame (wraps) |
| `$E202`–`$E203` | score, 16-bit little-endian, written by the cartridge; reported at game over |
| `$E204`–`$E205` | the credit's seed, 16-bit little-endian |

A game cartridge gets 3,000 instructions per 60 Hz frame (the site's "normal" speed). A credit ends
when the cartridge halts or after 120 seconds.

## Export

`.fkc` is not a Godot resource type. An export preset must list `*.fkc` (and `*.json`) in its
non-resource include filter, or these files will be missing from exported builds.
