## Findings and fixes

Severity: **High** = a player is blocked or loses something; **Medium** = wrong or broken in normal play;
**Low** = cosmetic, tool-only or rare.

### Fixed

1. **High: settings out of reach at 720p.** F2's panel was taller than a 1280×720 window: Apply, Close,
   Recalibrate, Online & voice and Test my wallet were below the bottom edge (`p1_f2.png`). It now scrolls
   inside the window and sits below the wallet chip (`p2_f2_bottom.png`). Mouse sensitivity read "0%"; it
   shows its value now (`SettingsMenu.slider_text`, tested).
2. **High: RPC reads timed out during loading.** HTTPRequest's Timer counted main-thread stalls (a build
   stage of 2–10 s on a slow PC) as node time: every read in flight "timed out", good nodes were marked
   unreachable and the game failed over in a loop (seen in both interactive launches; reproduced with a
   16 s stall). Requests now run on a thread and the timeout counts frames capped at 0.25 s
   (`Rpc.timeout_step`, tested). Concurrent failovers switch once and log the node that failed (the log
   used to say "publicnode unreachable — switched to publicnode").
3. **Medium: F2 did nothing in the Room, the Void, the arcade and the pub** although F1 lists it. Places
   now open the same settings; Esc closes F1/F2 there, and Use/B/T wait while they are open.
4. **Medium: panels under the chat dock.** F1, F2, the guide and opportunities lived on the HUD's layer
   (10), under the chat dock (11) and the wallet chip (12): the dock drew over the controls list. They have
   their own layer (26) now, one panel at a time, and Esc closes them (territory and front door).
5. **Medium: Swap Hall panel and the bar menu ran off a 720p window** with the access steps shown (Swap,
   Close and the pub's Pay row out of reach). Both scroll inside the window now.
6. **Medium: the fair dropped or broke on a development change.** `FairSite.set_dev_tier` ignored a tier
   change that arrived while the fair was building or a ride ran (the fair stayed at the old size), and
   rebuilt the fair under a midway game or while a ride ticket waited for the wallet; the ride it then
   started had been freed (after the player paid). The last tier asked for now waits until those end.
7. **Medium: macOS push-to-talk would kill the app.** The macOS preset had no
   `privacy/microphone_usage_description`; macOS terminates an app that opens the mic without it. Added it
   and `codesign/entitlements/audio_input=true` (checked in a local export: `NSMicrophoneUsageDescription`
   is in Info.plist and `com.apple.security.device.audio-input` in the signature).
8. **Medium (tools): `probe_bump.gd` no longer compiled.** `Config.particles()` in AvatarExtras, FairFx and
   FairKit is a compile error in any `-s` tool that reaches them. New `Shares.crowd/particles` read the
   autoload through the main loop (tested).
9. **Low: a hidden failing test.** `test_terrain` hit a SCRIPT ERROR (the ground mesh moved to a worker
   thread) and still printed "ok". `tests/run.gd` now fails any test that logs an engine or script error;
   the test waits for the mesh. `DeepFieldTerrain` finds Config without absolute-path errors off-tree and
   rebuilds the mesh if the level changes while its thread runs.
10. **Low: Sunny's subtitle covered the pub's prompt line.** The band sits above it now.

### Not fixed (reported)

- **Low: logs after a renderer relaunch are garbled.** The child rotates `godot.log` by copy + truncate
  while the parent still writes to it at exit, so the child's first lines are overwritten by the parent's
  exit lines (`ObjectDB instances leaked…`). Bug reports from weak-GPU machines will have a damaged start.
  A fix needs the parent to stop writing (e.g. a separate `--log-file` for the relaunch).
- **Low/perf: every launch on a machine that prefers Compatibility starts Forward+ and relaunches.**
  Works, but costs a Vulkan init and a window flash each launch. `application/config/project_settings_override`
  pointing at a `user://` file that holds the chosen renderer would start the right one directly.
- **Low: `SiteApi` and `UpdateCheck` HTTPRequests** have the same Timer-counts-stalls timeout as the RPC
  had (both optional, fail quietly).
- **Low: camera clips into the avatar** when backing into a wall (`p1_hall_exit.png`), and into the door
  frame mid door transition (`p1_hall.png`).
- **Low: 3D chat bubbles overlap seat HUD text** (top right in the Twenty-One seat, `shots/cards.png`); the
  wallet chip and notification bell overlap the top edge of tall panels (bar menu, swap panel, cards title).
- **Low: the place prompt line (800 px, centred) runs under the chat dock** at 720p (`exp_pool_prompt.png`:
  its key chip is hidden).
- **Low: the front door says "942 QINGs" on The Field door and "943" in the status strip** (snapshot vs the
  live NewQing scan).
- **Low (tool): `live_chat.gd` logs `grab_focus` outside the tree** when it changes scene into the arcade
  (a deferred focus call; no script backtrace, source not identified; not seen in play).
- Environment only: `TLS handshake error -27648` and `rpc.pulsechain.com` http 500 / publicnode 403 were
  seen through this sandbox's proxy; the failover handled them.
- Known, unchanged: `icon.svg` is still Godot's stock logo; the installer is unsigned.
- Keys bound twice on purpose (contextual): G (guide / Field warp), V, Enter, Space.

### Checked and fine

- Every `res://` path in scripts/scenes/tools exists (dynamic paths checked by hand); nothing at runtime
  reads `tools/`, `tests/` or `docs/`.
- Every non-resource file read at runtime is in `include_filter` (`assets/data/*.json`,
  `assets/web/wallet.html`, cartridges `.fkc` + `manifest.json`); no runtime `DirAccess` listing of `res://`.
- Every input action used in code is bound in `project.godot`.
- RichTextLabel BBCode from chain/chat text is escaped (`ChatLines.esc`, `ChatPanel._esc`, Inspector).
- Windows export: version resources come from `config/version` (release.yml writes it), company/product
  set, icon set by release.yml; the export holds exactly `Dysnomia.exe` + `Dysnomia.pck`. Local wallet relay
  binds 127.0.0.1 only (no macOS firewall prompt).
- The relaunch from an exported binary uses no `--path` and works.
